# Bibliothèque numérique — Projet Java UA3

## Étudiante

Assia Benmazouz

## Description

Cette application Java permet de gérer une bibliothèque numérique contenant plusieurs types de documents : livres, magazines et livres audio.

## Fonctionnalités

- Chargement de 15 documents à partir d’un fichier CSV.
- Validation des données et détection des lignes invalides.
- Gestion de différents types de documents par héritage.
- Emprunt et retour des documents.
- Recherche d’un document par identifiant.
- Affichage du nombre de documents par catégorie.
- Affichage du document le plus emprunté.
- Affichage des documents jamais empruntés.
- Génération d’un rapport TXT.

## Concepts Java utilisés

- Héritage
- Classe abstraite
- Interface
- ArrayList
- Exceptions personnalisées
- Lecture et écriture de fichiers
- Principes SOLID : SRP et OCP

## Exécution

1. Ouvrir le projet dans IntelliJ IDEA.
2. Vérifier que le fichier `Assia/data/documents.csv` est présent.
3. Ouvrir `Assia/src/Main.java`.
4. Exécuter la méthode `main`.
5. Consulter le rapport généré dans :

`Assia/data/rapport_bibliotheque.txt`
